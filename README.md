# monis.rent — Workspace Designer

An interactive tool to design your dream workspace and rent it.

## Approach
- **Next.js + TypeScript** for framework
- **Tailwind CSS** for styling
- **Framer Motion** for smooth animations
- **Zustand** for lightweight state management
- **Lucide React** for icons

## Features
- Choose from multiple desks, chairs, accessories
- Live visual preview updates as you select
- Real-time summary with monthly pricing
- One-click WhatsApp checkout

## What I'd improve with more time
- Drag-and-drop positioning of accessories
- 3D preview using React Three Fiber
- Real product images from monis.rent API
- User accounts and saved setups
